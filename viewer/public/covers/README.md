# AI cover pages

Each show reads its cover page from this folder (`viewer/public/covers/`).
Drop one image per show here and it will appear as the show's hero/banner in
the viewer. A `.webp` file is expected; if it's absent the viewer falls back
to the existing episode artwork, so nothing breaks before the image is added.

| Show | Expected file |
|---|---|
| The Jungle Crew | `jungle-crew.webp` |
| Tales of the Deep | `tales-of-the-deep.webp` |
| Little Scientists | `little-scientists.webp` |
| Space Rovers | `space-rovers.webp` |
| The Lost Kingdom | `the-lost-kingdom.webp` |
| Comedy Canvas | `comedy-canvas.webp` |
| Wonder Woods | `wonder-woods.webp` |
| Ocean Detectives | `ocean-detectives.webp` |

Suggested size: 16:9 landscape (e.g. 1280×720 or larger, ≤ a few hundred KB).
The hero banner crops to fit, so a wide source image gives the best result.
